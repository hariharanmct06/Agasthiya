## 🌐 Deployment to GitHub Pages

This project is built with vanilla HTML5, CSS3, and modern JavaScript. It has zero external runtime build dependencies.

1. Go to your repository on GitHub: `https://github.com/hariharanmct06/Agasthiya`
2. Navigate to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then click **Save**.
5. Your website will be live in minutes at `https://hariharanmct06.github.io/Agasthiya/`!
